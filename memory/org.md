# Team lessons

- For consulting firms, solution_fit is inherently strong — desktop-heavy knowledge work (research, analysis, strategy, reporting) is core Zeami territory. Don't ask the user to explain this every time. <!-- mem_babd · added 2026-05-31 by mateo · from deal 7abdc782 -->
- Zeami sales motion is always: (1) observe desktop work → (2) system outlines workflows and prices them → (3) show workflow value in ROI priority order → (4) customer decides which agents to deploy based on ROI (cost of agent vs. savings). Agent pricing is typically 20% of customer's savings from that agent. <!-- mem_fc63 · added 2026-05-31 by mateo · from deal 7abdc782 -->
